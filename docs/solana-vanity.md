# Solana 靓号地址

**入口**：顶部导航「Solana」→「✨ 靓号地址」页签

生成一个开头或结尾带指定字符的 Solana 钱包地址，比如以 `SHARK` 开头。

**费用**：免费。**纯本地计算，不需要连接钱包、不发起任何链上交易。**

> 🔐 **私钥不会离开你的浏览器**。生成过程完全在你的电脑本地完成。

---

## 操作步骤

1. 填 **「前缀」**（默认给的是 `SHARK`），**「后缀」** 可选。
2. 页面会实时显示**预计难度**和「每多 1 位 ×58」的提示——每多指定一个字符，难度就乘以 58 倍。
3. 点 **「开始生成」**，页面显示「已尝试 XXX 次 · 运行中」。想停就点「停止」。
4. 命中后会提示 **「🎉 命中靓号 XXXX」**，并出现在右侧「命中的地址」列表里。
5. 点每条结果上的 **「导出」** 按钮，会下载一个 JSON 文件，可直接导入 Phantom / Solflare。

### 字符集说明

Solana 使用 Base58，**已去掉容易看错的 `0`、`O`、`I`、`l`**。

### 难度建议

- 前缀 + 后缀**合计超过 5 位**，难度极高，可能跑不出来，页面会提示你减少字符。
- 位置越多越慢，建议从 2–3 位开始试。

---

## ⚠️ 拿到结果后第一件事：导出并离线备份

页面上的提示请务必照做：

> 结果**只保存在当前页面内存中，刷新即清空**。请立即导出 JSON 并离线备份私钥——**这是钱包的完整控制权**。

导出的 JSON 就是钱包私钥文件，谁拿到都能转走里面的资产，请：

- 立刻导出，别刷新页面；
- 存放在离线、加密的位置；
- 不要截图、不要发到聊天工具、不要上传到网盘或任何网站。
