# 定制开发

**入口**：顶部导航「定制」

除了自助工具，SharkTool 也承接各类区块链定制开发需求。

---

![定制开发页：可承接的方向与联系入口](images/custom.png)

## 可承接的方向

| 方向 | 举例 |
|---|---|
| **代币合约** | 带税、分红、反狙击、自定义机制的合约开发 |
| **交易机器人** | 监控、狙击、跟单、自动交易类机器人 |
| **钱包与工具** | 批量钱包、批量转账、归集、靓号等工具 |
| **DEX 与流动性** | 建池、撤池、流动性管理、做市脚本 |
| **前端与面板** | 数据面板、管理后台、监控看板 |
| **安全与审计** | 合约风险检测、代码审计 |

## 支持的网络

BSC · Ethereum · Polygon · Arbitrum · Base · Solana · Tron

---

## 交付流程

1. **沟通需求** —— 说明你要做什么、跑在哪条链、预期效果
2. **评估报价** —— 确认技术方案、工期与费用
3. **开发与联调** —— 开发过程中同步进度，可阶段性验收
4. **交付与支持** —— 交付可用成品，并提供必要的使用说明
