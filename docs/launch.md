# 代币克隆

**入口**：顶部导航「代币克隆」（也可以从「代币分析」结果页点「🚀 克隆此代币」进来）

**源码级 100% 克隆**：把已开源的合约源码抓下来，在浏览器里精确编译，再把参数填一填就能部署出一个**字节码与原合约完全一致**的新代币。

**前置条件**：

- **必须在右上角选好网络**，并且这个功能只对 **BSC 主网 / BSC 测试网** 有完整支持。
- **必须连接钱包**（MetaMask 或扫码），部署和手续费都由钱包签名。
- **必须是已开源的合约**——未开源的合约无法克隆。
- **收费**：收平台服务费，具体金额以页面显示与钱包弹窗为准；会员有效期内免费。

---

## 操作步骤

### 第 1 步：获取源码并编译

1. 在「源码级克隆引擎」区块的输入框里粘贴合约地址（placeholder 提示：`请输入已验证的合约地址 (0x...)`）。
2. 点 **「获取源码·编译·生成表单」**。按钮依次显示「获取源码中...」→「编译源码中...」→「分析中...」。
3. 成功后提示 **「✅ 源码获取、编译与构造参数解析完成！百分百克隆已就绪」**，并出现「百分百克隆」徽章，显示合约名称、编译器版本、优化器设置、构造参数数量。

### 第 2 步：选择克隆方式

页面提供三种方式，默认是第一种：

| 方式 | 说明 |
|---|---|
| **源码克隆**（默认） | 编译原合约源码，字节码 100% 一致。**推荐** |
| **简易模板** | 标准 ERC20，只填名称、符号、精度、总供应量 |
| **完整模板** | 带税 / 限额 / 交易开关的模板，可填合约所有者、税收钱包、买入税、卖出税、单笔最大交易量、最大持仓量、是否开启交易 |

### 第 3 步：填写参数

选「源码克隆」时，页面会自动列出：

- **构造函数参数定义**：按原合约 ABI 自动生成表单，链上原本的参数值已自动预填。
- **源码硬编码参数**：源码里写死的税率、钱包地址、供应量上限等，已预填原值，可以改。

每个参数旁边有 **「🤖 解读」** 按钮，点一下会用中文告诉你这个参数是什么、该怎么填；顶部还有 **「🤖 AI 解读全部参数」** 一次全解。

> 有些参数是复杂表达式（引用了其他常量或计算结果），这类会标注「暂不支持修改，部署时原样保留」。

### 第 4 步：确认部署钱包

页面会显示 **「部署钱包」** 区块。已连接时显示你的地址和连接方式；未连接时会提示你先去右上角连接。

> 部署与手续费支付都由钱包弹窗签名，**无需输入私钥**。

### 第 5 步：一键部署

1. 点 **「一键部署百分百源码级克隆合约」**（模板模式按钮文案为「一键部署模板克隆合约」）。
2. 部署过程中会显示「正在部署克隆合约 (步骤 X/2)...」。
3. **如果在主网部署，会先弹一个确认框**，提醒你正在支付真实手续费，确认后继续。
4. 收费流程是**两笔**：先转服务费，再发部署交易（会员免费时只有部署交易）。
5. 成功提示 **「🎉 恭喜！克隆合约部署成功！」**。

### 第 6 步：拿到结果

成功卡片上会显示：

- **新合约地址** —— 有「复制地址」按钮
- **部署交易哈希** —— 有「复制哈希」按钮
- **部署者与税收归属** —— 税收会自动绑定到部署者钱包

想接着再发一个，点 **「继续部署新合约」**。

---

## 部署后：手动开源合约（可选）

新合约默认不一定自动开源。成功卡片里有一整块 **「合约开源信息（区块浏览器手动验证用）」**，按区块浏览器「Verify & Publish Contract Source Code」表单需要的字段逐项给出：

- 编译器类型、编译器版本、开源协议、EVM 版本、优化开关、Optimizer Runs（每项都有复制按钮）
- **Solidity Contract Code**：可「一键下载源码」或「复制全部源码」
- **Constructor Arguments ABI-encoded**：可「复制 ABI 编码」；如果合约没有构造参数，这一栏留空即可

> 如果代码是多文件的，页面会提示你用区块浏览器的「SOLIDITY MULTI-PART VERIFIER」并粘贴 JSON 格式的源码。

## 常见提示

| 提示 | 原因 / 怎么办 |
|---|---|
| `请输入要克隆的合约地址` / `合约地址格式不正确` | 地址没填或写错 |
| `该合约未开源，无法百分百克隆` | 换一个已开源的合约 |
| `不支持多文件合约：请选择单文件合约` | 该合约是多文件结构，暂不支持 |
| `编译失败: ...` | 源码编译不通过，可联系客服 |
| `请先完成合约分析` | 跳过了「获取源码·编译」步骤 |
| `请先连接钱包（MetaMask 或扫码）` | 去右上角连接钱包 |
| 提示缺少区块浏览器密钥 | 平台侧接口未就绪，稍后再试或联系客服 |
