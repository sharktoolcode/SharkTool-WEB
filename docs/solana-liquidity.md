# Solana 流动性

**入口**：顶部导航「Solana」→「🌊 流动性」页签

为你的 SPL 代币创建真实流动性池并注入初始流动性，也可以随时撤回（销毁 LP 赎回两种币）。

**前置条件**：

- 连接 **Solana 钱包**。
- 在 Solana 页面顶部选好 **Mainnet / Devnet**。
- **收费**：Raydium 建池费 + 注入的流动性 + 账户租金，另有平台服务费（页面会列明细）。会员有效期内免平台服务费。

## 建池步骤

1. 选择 **Raydium**。
2. 填写建池表单：

| 字段 | 说明 |
|---|---|
| **代币** | 从下拉里选你要建池的代币 |
| **初始 SOL 注入量** | 池子里放多少 SOL |
| **初始代币注入量** | 池子里放多少代币 |
| **初始价格** | 由上面两个数值自动算出（只读） |

3. 核对右侧**费用明细**：建池费、注入流动性、账户租金、平台服务费、合计。
4. 点 **「🌊 创建池子并注入流动性」**，钱包签名确认。
5. **主网建池会弹确认框**，明确提示会花真实 SOL（建池费不退、注入金额、租金等），确认后继续。
6. 成功后提示 **「🎉 流动性池已创建」**。

## 我的流动性

建成后（或手动添加外部池子后）会出现在「我的流动性」区：

- 显示池子、你的 LP 数量与占比。
- **撤回**：撤回 = 销毁 LP，按份额赎回两种币。
  - 可以填「撤回 LP 数量」，或点 **「全部」** 一次撤完。
  - 点 **「✕」** 只是从列表里移除记录，**不影响链上池子**。
- **添加已有池子**：粘贴池子地址点「添加」，可以把在别处建的池子也纳进来管理。

> ⚠️ 撤回时赎回到的两种币数量会**随行情变化**，且**建池费不退**。主网撤回会真实上链，请确认后再操作。

## 常见提示

| 提示 | 说明 |
|---|---|
| `不是合法的池子地址` | 粘贴的池子地址格式不对 |
| `撤回失败: ...` | 交易失败，重试或检查余额 |
| 建池失败 | 检查 SOL 余额是否够建池费 + 注入量 + 租金 |
