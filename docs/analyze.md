# 代币分析

**入口**：顶部导航「代币分析」

输入一个合约地址，得到一份链上体检报告：基本信息 + 14 项风险检测。用来快速判断「这个币能不能碰」。

**费用**：免费。**不需要连接钱包**（纯链上只读查询，不会发起任何交易）。

---

![代币分析页：填入合约地址后点「开始分析合约」](images/analyze.png)

## 操作步骤

1. 先在**右上角选择好网络**（BSC 主网、Ethereum、Polygon、Arbitrum、Base 等）。页面顶部会显示「当前网络：XXX（右上角可切换）」。
2. 在 **「合约地址 (Contract Address)」** 输入框里粘贴代币合约地址。输入框左边已经带好 `0x` 前缀。
3. 懒得上 BscScan 复制地址的话，可以点右侧小字 **「填入示例 XXX 地址」**，会一键填入该链的 USDT（Base 链是 USDC）示例地址。
4. 点 **「开始分析合约」**。
5. 等待链上查询完成（按钮会变成「正在链上分析合约…」），成功后提示 **「合约分析成功！」**。

## 结果怎么看

### 基本信息

包括：Token Name、Symbol、Chain、合约地址（可点击复制）、发行量、精度、销毁比例、合约所有权、合约是否开源、合约名、编译器版本、开源协议、代理实现地址。

其中两个点值得留意：

- **合约是否开源**：显示「代码已开源」或「未开源 / 无法审计」。想用「代币克隆」功能的话，**必须是已开源的合约**。
- **合约创建者**：目前区块浏览器未提供该信息，会显示 `-`，需要的话去查看创建交易。

### 风险分析（14 项）

每一项会给出「安全 / 风险 / 需确认」的判断：

| 检测项 | 说明 |
|---|---|
| 买入费率 / 卖出费率 | 买卖时被扣的税 |
| 当前是否貔貅（蜜罐） | 能买不能卖 |
| 是否可修改费率 | owner 事后把卖出税改到极高 |
| 是否限制大额交易 | 单笔/持仓上限 |
| 是否可找回管理权限 | 权限是否可能被收回 |
| 是否有地址黑名单 | owner 可拉黑地址 |
| 是否有白名单卖出 | 只有白名单能卖 |
| 是否可增发砸盘 | 能否凭空增发 |
| 是否代理合约 | 逻辑可被替换 |
| 是否可暂停交易 | owner 可一键停盘 |
| 是否有交易冷却 | 限制交易频率 |
| 是否可源码审计 | 代码是否可查 |

> ⚠️ 页面上的提示值得读一遍：**「可暂停交易」和「可修改费率」风险较大**——卖出费率被 owner 改成 99% 就变貔貅，暂停交易也能变貔貅。
>
> 检测结果基于本地字节码 / ABI 特征探测，**仅供参考，不构成投资建议**。

## 分析完想复刻这个币？

结果下方有一张 **「克隆这个代币？」** 卡片，点 **「🚀 克隆此代币」** 会跳到代币克隆页面，并自动带上刚分析的地址。

前提是**该合约已开源**。详细流程见 [代币克隆](launch.md)。

---

## 常见提示

| 提示 | 原因 |
|---|---|
| `请输入有效的合约地址` | 地址没填或格式不对 |
| `合约分析失败，请检查 RPC 或网络连接` | 链上节点异常，稍后重试 |
| 合约没开源 | 只能看到基本信息，无法做源码级克隆 |
