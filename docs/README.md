## 三分钟上手

1. **打开官网** <https://sharktool.shop>，右上角点 **「👛 连接钱包」**，选 MetaMask / 浏览器钱包，或用手机钱包扫码连接。
2. **在右上角选择网络**（BSC 主网、Ethereum、Polygon、Arbitrum、Base 等）。切网络时网站会提示你的钱包一起切换。
3. **选一个工具开始用**：只想查币就进「代币分析」，想发币就进「代币克隆」或「模块化发币」。

> 💡 浏览器钱包（MetaMask 等）建议在电脑上使用；手机上用 WalletConnect 扫码即可，全站通用，连接一次即可。
