# 安全与风险提示

这一页说明 SharkTool 在安全上是怎么设计的，以及你需要自己注意什么。

---

## 平台的安全设计

### 私钥永不外传

- **靓号生成、批量工具**等功能都在**你的电脑本地运算**，平台不索取、不存储任何私钥或助记词。
- 平台**永远不会**主动向你索要私钥、助记词或助记词截图——任何索要的都是骗子。

### 链上操作由你自己签名

发币、建池、调用合约函数等每一笔交易，都会弹出你的钱包让你确认。平台无法替你动用资产。

### 工具类页面只读

代币分析、监控、靓号等功能只做查询与本地计算，**不触碰资产**。

### 第三方接口在服务端代理

AI 解读、区块浏览器查询等能力由服务端统一对接，**浏览器端不持有任何第三方密钥**。

---

## 你需要自己注意的事

### 1. 签名前务必核对

- 核对**合约地址**是不是你要操作的币；
- 核对**交易内容**（转给谁、转多少、调用什么函数）；
- 核对**网络**是不是你要用的链（网站右上角与钱包里要一致）。

### 2. 靓号私钥就是钱包本身

靓号命中后导出的 JSON 文件 = **钱包的完整控制权**。谁拿到都能把资产转走。

- 立刻导出，别刷新页面；
- 离线加密保存；
- 不要截图、不要发聊天工具、不要传网盘。

### 3. 区块浏览器的分析结果仅供参考

代币分析基于本地字节码 / ABI 特征探测，**不构成投资建议**，也无法保证发现所有风险（尤其是代理合约、动态逻辑等复杂情况）。

### 4. 自定义机制有额外风险

- 你部署的带税 / 分红 / 复利等机制的代币，**经济模型与合规性由你自己负责**。
- 请确保你的代币用途合法合规，不要用于欺诈。

### 5. 会员凭证不要外借

会员凭证保存在本浏览器、不绑定钱包，理论上可被复制分享。请勿转让；清除站点数据或更换浏览器会导致会员丢失。

---

## 免责声明

链上资产操作存在风险，请务必核对合约地址与交易内容后再签名。本平台提供的分析结论仅供参考，不构成投资建议。

**本工具仅供技术学习与合法合约部署测试使用。用户需自行对部署合约的合规性、安全性和经济模型负责。**
