# 常见问题

## 钱包相关

**Q：支持哪些钱包？**

- **EVM 链**：MetaMask、OKX、Trust、Coinbase 等浏览器插件钱包，以及通过 WalletConnect 扫码的手机钱包。
- **Solana**：Phantom、Solflare、Backpack。

**Q：连接钱包会拿走我的私钥吗？**

不会。私钥始终保存在你的钱包里，网站无法接触。所有交易都要你在钱包里确认。

**Q：为什么发币时提示"请先在钱包中切换到目标网络"？**

网站右上角的网络和钱包里的网络不一致。在钱包里手动切到同一个网络再重试即可。

**Q：刷新页面要重新连接吗？**

不需要，会自动恢复上次的连接状态。

## 代币分析

**Q：分析收费吗？**

免费，也不需要连接钱包。

**Q：为什么"合约创建者"显示 `-`？**

区块浏览器目前未提供该信息，需要自己去查看创建交易。

**Q：分析结果能保证这个币安全吗？**

不能。结果基于字节码 / ABI 特征探测，**仅供参考**，不构成投资建议。

---

## 代币克隆

**Q：为什么提示"该合约未开源，无法百分百克隆"？**

克隆需要拿到原合约的源码。只有已在区块浏览器**验证开源**的合约才能克隆。

**Q：克隆出来的币和我发的新币有什么区别？**

克隆保证**字节码与原合约一致**，但**不保证业务逻辑安全**——原合约有坑，克隆出来一样有坑。

**Q：部署收多少服务费？**

以页面显示和钱包弹窗为准。会员有效期内免费。详见[服务费说明](fees.md)。

**Q：克隆要签几次名？**

通常**两次**：先转服务费，再发部署交易。会员免费时只需一次。

## 模块化发币

**Q：为什么我加了税模块，但实际买卖没扣税？**

税只对**注册过的真实交易池**生效。部署后需要在页面里「注册 AMM 交易对」，税才会开始收。

**Q：能指定合约地址的前缀 / 后缀吗？**

可以。但**超过 4 位可能需要很长时间甚至找不到**，每多 1 位难度 ×16。

**Q：买卖税率有上限吗？**

有，买卖总税率必须小于 25%，超出会校验失败。

## 代币控制台

**Q：为什么有的代币没有"管理功能"？**

控制台需要合约 ABI。**合约未开源就拿不到 ABI**，管理功能不可用。

**Q：从控制台"移除"会删掉链上合约吗？**

不会，只是从本地列表移除，链上代币不受影响。

## Solana

**Q：Solana 能用 MetaMask 吗？**

不能。Solana 需要 Phantom / Solflare / Backpack。

**Q：想在测试网练手怎么办？**

在 Solana 页面顶部切到 **Devnet**，会出现「💧 领测试币」按钮，可免费领 1 SOL。

**Q：Solana 发币一共要花多少钱？**

包括账户租金（Mint、代币账户、元数据）、网络交易费、平台服务费。页面右侧有完整明细和合计。

**Q：靓号生成的私钥安全吗？**

生成过程完全在本地，私钥不出浏览器。但**导出后的 JSON 就是钱包本身**，请离线加密备份，别截图、别外发。

**Q：建池后能撤回来吗？**

可以，销毁 LP 按份额赎回两种币。但**数量会随行情变化，建池费不退**。

## 会员

**Q：会员能省什么？**

有效期内**全站发币 / 建池服务费全免**（不限次数）+ **商城源码折扣**。

**Q：会员绑定钱包吗？**

不绑定。会员凭证保存在本浏览器，全站通用。

**Q：换电脑 / 清缓存后会员还在吗？**

不在。会员保存在浏览器本地，清除站点数据或换设备会丢失，需要重新购买。

**Q：续费是叠加还是覆盖？**

叠加。有效期内再买一次，时长会累加。

## 商城

**Q：支持哪些支付方式？**

BSC BNB、BSC USDT、Tron USDT、Solana SOL、Solana USDT。

**Q：支付后多久能拿到源码？**

页面会自动监听链上到账，确认后立即解锁下载。如果迟迟没到账，可以用「手动提交交易哈希」兜底。

**Q：能退款吗？**

源码为虚拟商品，**付款成功后不支持退款**。

**Q：能二次售卖买到的源码吗？**

不能，仅限购买者本人使用。
