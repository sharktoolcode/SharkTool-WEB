# 代币控制台

**入口**：顶部导航「控制台」

集中管理你发过的代币：查看链上实时状态，直接在线调用合约的管理函数（改税率、加黑名单、暂停交易、增发、销毁、放弃所有权……）。

**费用**：免费（调用函数只需付链上 Gas，平台不额外收费）。

**前置条件**：

- 在右上角选好网络。
- **查看状态不需要钱包**；**执行管理函数必须连接钱包**。

## 操作步骤

### 添加代币

有两种方式：

- **自动收录**：凡是在本平台部署过的代币，会自动出现在列表里（标记「我的部署」）。
- **手动添加**：在顶部输入框粘贴合约地址，点 **「添加」**，提示「已添加到控制台」。

> 手动添加的合约**必须已开源**，否则拿不到 ABI，管理功能不可用。

### 查看链上实时状态

点列表里的代币进入详情页：

- **基本信息卡**：名称、符号、链、地址，可跳转区块浏览器，也可从控制台「移除」（只影响本地列表，不动链上合约）。
- **链上实时状态**：自动读取合约公开的 getter，显示当前税费、上限、权限等实时值。

### 调用管理函数

1. 展开 **「管理功能（合约可调用函数）」** 里的某个函数。这里只会列出真正能改状态的管理函数（改税率、改钱包、开关、黑名单等），标准转账类函数已排除。
2. 按提示填参数（地址类填 `0x...`；数组类按示例格式填；数值类注意单位，税率类通常是千分比）。
3. 点 **「执行 函数名()」**，钱包签名确认。
4. 页面依次提示「正在调用…」→「等待交易确认...」→「✅ 交易已确认」，并给出交易链接。

### AI 函数解释

每个函数旁边有 **「🤖 解释」** 按钮，点一下会说明：这个函数是做什么的、调用有什么风险、参数该怎么填。

## 常见提示

| 提示 | 说明 |
|---|---|
| `请输入有效的合约地址` | 地址格式不对 |
| `无法获取合约信息（未开源或地址无效）` | 合约没开源，或地址不存在 |
| `暂无已部署代币` | 列表为空，可去发币或手动添加 |
| `未获取到可写函数（需要合约 ABI，未开源则不可用）` | 合约未开源 |
| `⚠️ 未连接钱包，执行需先连接（右上角）` | 执行函数前先连接钱包 |
| `未获取到合约 ABI（未开源？），管理功能不可用` | 同上 |

> 💡 控制台只对「管理类」函数开放，**不会**替你执行转账类操作；任何调用都要你在钱包里确认。
