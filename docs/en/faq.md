# FAQ

## Wallets

**Q: Which wallets are supported?**

- **EVM chains**: browser extension wallets such as MetaMask, OKX, Trust and Coinbase, plus mobile wallets connected by scanning with WalletConnect.
- **Solana**: Phantom, Solflare, Backpack.

**Q: Does connecting a wallet take my private key?**

No. The private key always stays in your wallet and the website cannot touch it. Every transaction has to be confirmed in your wallet.

**Q: Why does launching a token say “please switch to the target network in your wallet” first?**

The network in the top-right of the site and the network in your wallet don't match. Switch to the same network manually in your wallet and retry.

**Q: Do I need to reconnect after refreshing the page?**

No — the previous connection is restored automatically.

## Token Analysis

**Q: Is analysis charged for?**

It's free, and you don't need to connect a wallet.

**Q: Why does “contract creator” show `-`?**

The block explorer doesn't provide that information at the moment, so you have to look at the creation transaction yourself.

**Q: Does the analysis guarantee the token is safe?**

No. The results are based on bytecode / ABI feature detection and are **for reference only**; they are not investment advice.

## Token Cloning

**Q: Why does it say “this contract is not open source, so a 100% clone isn't possible”?**

Cloning needs the original contract's source code. Only contracts that have been **verified as open source** on a block explorer can be cloned.

**Q: What's the difference between a cloned token and a new token I launch?**

Cloning guarantees **the bytecode matches the original contract**, but **doesn't guarantee the business logic is safe** — if the original has a pitfall, the clone has the same pitfall.

**Q: How much service fee do you charge for deployment?**

What the page and the wallet popup show is what applies. It's free while your Membership is active. See [Service Fees](fees.md) for details.

**Q: How many signatures does cloning need?**

Usually **two**: first the service fee, then the deployment transaction. With free membership it's only one.

## Modular Launchpad

**Q: I added a tax module, but why is no tax deducted on actual buys and sells?**

The tax only applies to **registered real trading pools**. After deploying, you need to “register the AMM trading pair” on the page before the tax starts being collected.

**Q: Can I specify a prefix / suffix for the contract address?**

Yes. But **more than 4 characters can take a very long time or may never be found**, and each extra character multiplies the difficulty ×16.

**Q: Is there a cap on the buy/sell tax rate?**

Yes — the combined buy and sell tax rate must be less than 25%; anything above fails validation.

## Token Console

**Q: Why do some tokens have no “management features”?**

The console needs the contract ABI. **Without open source you can't get the ABI**, so management features are unavailable.

**Q: Does “Remove” from the console delete the on-chain contract?**

No, it only removes the entry from your local list; the on-chain token is unaffected.

## Solana

**Q: Can I use MetaMask on Solana?**

No. Solana needs Phantom / Solflare / Backpack.

**Q: What if I want to practise on a testnet?**

Switch to **Devnet** at the top of the Solana page, and a “💧 Claim test funds” button appears that lets you claim 1 SOL for free.

**Q: How much does launching a Solana token cost in total?**

It includes account rent (mint, token account, metadata), the network transaction fee and the platform service fee. The right side of the page has the full breakdown and total.

**Q: Is the private key generated by the vanity generator safe?**

The generation happens entirely locally and the private key never leaves the browser. But **the exported JSON is the wallet itself**, so back it up offline and encrypted — no screenshots, no sending it out.

**Q: Can I withdraw after creating a pool?**

Yes — burn LP to redeem both tokens by share. But **the amounts change with the market, and the pool creation fee is not refunded**.

## Membership

**Q: What does Membership save me?**

While it's active, **launch / pool creation service fees are waived site-wide** (unlimited use) plus a **shop source-code discount**.

**Q: Is Membership tied to a wallet?**

No. The membership credential is stored in this browser and works across the site.

**Q: Does Membership survive a new computer / clearing the cache?**

No. Membership is stored locally in the browser; clearing site data or switching devices loses it, and you'd need to buy it again.

**Q: Does renewing stack or overwrite?**

It stacks. If you buy again while it's active, the time is added on.

## Shop

**Q: Which payment methods are supported?**

BSC BNB, BSC USDT, Tron USDT, Solana SOL, Solana USDT.

**Q: How long after paying do I get the source code?**

The page automatically watches for the on-chain payment and unlocks the download as soon as it's confirmed. If it doesn't arrive for a long time, you can fall back to “manually submit the transaction hash”.

**Q: Can I get a refund?**

Source code is a virtual product, so **refunds are not supported after a successful payment**.

**Q: Can I resell the source code I bought?**

No, it's for the buyer's own use only.
